# Lions Task — Self-Evolving Cognitive Flywheel

## 架构设计

```
┌─────────────────────────────────────────────────────────────────┐
│                        每日循环                                   │
│                                                                  │
│  00:05  每日总结生成                                               │
│    ↓                                                              │
│  00:10  遗留项 → 自动创建 Task                                     │
│    ↓                                                              │
│  定时   Agent 执行 Task                                           │
│    ↓                                                              │
│  执行中 → Problem 被发现并记录                                      │
│    ↓                                                              │
│  完成   → TaskReflection (自动反思)                                 │
│    ↓                                                              │
│  反思改进项 → 新 Task (循环回到执行)                                 │
│    ↓                                                              │
│  Problem解决 → ProblemReflection                                  │
│    ↓                                                              │
│  00:05  次日总结 (包含问题解决+任务完成)                             │
└─────────────────────────────────────────────────────────────────┘

## 新增数据模型

### Problem (问题记录)
- id, taskExecutionId, taskId
- description (问题描述)
- severity: P1/P2/P3
- status: OPEN/SOLVING/SOLVED/ABANDONED
- solutionsAttempted (尝试过的解决方案)
- rootCause (根本原因)
- resolvedAt
- reflections (关联反思)

### TaskReflection (任务反思)
- id, taskId, executionId
- whatWentWell (做得好的)
- whatCouldBeBetter (可以改进的)
- lessonsLearned (学到的)
- improvements (需要改进的具体项)
- score: 0-10
- autoGenerated: Boolean (是否自动生成)

### ProblemReflection (问题反思)
- id, problemId
- rootCause (分析)
- solution (解决方案)
- lessons (经验教训)
- transferable (是否可迁移到其他任务)

## Agent 流程

### TaskExecutor 执行步骤
1. 读取 Task 完整信息
2. 制定执行计划 (thoughtProcess)
3. 执行并记录问题 (Problem)
4. 解决问题
5. 自评质量
6. 触发 TaskReflection

### AutoReflector (自动反思 Agent)
- 触发时机: Task完成 / Problem解决
- 输入: TaskExecution + Task + Problems
- 输出: TaskReflection + 改进建议 → 新Task

## 循环机制

1. Task执行中 → 发现Problem → 记录 → 继续执行
2. Task完成 → AutoReflector → TaskReflection + 改进Task
3. Problem解决 → AutoReflector → ProblemReflection + 改进Task
4. 每日总结 → 包含: 完成Task数、解决问题数、反思洞察
